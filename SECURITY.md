# Reporting a vulnerability

For a sensitive security issue in Ibrahim Tools, email **connect@ibrahimwali.com** with the subject **Ibrahim Tools security report**.

Include the affected tool or file, a description of the issue, its potential impact, and minimal reproduction steps using synthetic data. Do not send real credentials, private files, or other people's information.

Please avoid publishing exploitable details in a public GitHub issue before the maintainer has had an opportunity to investigate. No response-time commitment or bounty program is currently specified.
